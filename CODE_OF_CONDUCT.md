# Code of conduct

We want NaluzPHP to be a welcoming place to learn, ask questions and contribute.

- **Be respectful.** Disagree with ideas, never attack people. No harassment, discrimination, or personal attacks.
- **Be constructive.** Review code kindly, give reasons, assume good intent, and help newcomers.
- **Keep it professional.** No sexual content, doxxing, or spam in issues, pull requests or discussions.
- **Respect privacy and security.** Report vulnerabilities privately (see SECURITY.md); never post other people's data.

Maintainers may edit, hide or remove contributions that violate these rules and may ban repeat offenders.
Report concerns to anthony.naluz15@gmail.com; reports are handled confidentially.
